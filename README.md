One line, 1 to 240 characters, that gives the judge a quiet, earned moment of pride for someone in a scene. Free to enter, judged in pairs on genuine earned pride, a concrete scene, landing in one read and freshness.

The program writes one line to `/output/entry.txt`, chosen by a 32-candidate
tournament judged against the house judge's published brief (see
`candidates.md` in the build workspace):

> On the third spring the grafted branch bloomed, and the old orchardist pressed his palm flat against the bark.

Deterministic, no network, no randomness: every run writes the same 110 bytes.

## Run it

```sh
python3 main.py
```
